# CSV 批量导入

卡包支持从标准 UTF-8 CSV 文件批量导入银行卡和证件。CSV 是明文迁移格式，不是备份格式；文件可能包含卡号、CVV 和证件号，使用后应由用户自行妥善删除。正式备份请使用加密的 `.kabao` 格式。

## 模板

- `templates/kabao-cards-template.csv`：银行卡（`category_type` 为 `debit` 或 `credit`）。
- `templates/kabao-documents-template.csv`：证件（`category_type` 为 `document`）。

应用设置中分别选择“导入银行卡 CSV”或“导入证件 CSV”。应用读取 UTF-8（含 BOM）、支持标准 CSV 引号和单元格换行。表头必须与模板一致且不能重复；每行列数必须一致。模板中的“（可选）”表示可以留空，由系统生成或按默认值处理。

## 分类和 ID

优先使用 `category_id` 关联现有分类；不填时使用 `category_type + category_name` 匹配，不存在则在确认后创建。`id` 可留空，应用会生成 UUID；填写时必须是 UUID。相同 ID 按现有 `.kabao` 导入规则，以更新时间较新者合并，不删除本地记录。银行卡类型可填 `debit`/`借记卡` 或 `credit`/`信用卡`，证件类型可填 `document`/`证件`。

## 校验与安全

文件会先完成全部行校验，存在任何错误时整批不写入。预览只显示行数、记录数、待创建分类数和错误行号，不显示敏感值。通过确认后，分类与记录在一个数据库事务中写入加密数据库，并重新计算到期提醒。

银行卡字段：卡号 1-19 位数字（可含空格或分隔符）、有效期 `MM/YY`、CVV 3 位数字、U 盾日期 `yyyy/M/d`、备注最多 500 字。

证件字段：证件号最多 20 位数字、签发机关必填；非长期有效时必须填写 `yyyy.MM.dd` 的起止日期且结束日期不能早于开始日期；长期有效填写 `validity_permanent=true`（或 `1`、`是`），并保持日期为空。
