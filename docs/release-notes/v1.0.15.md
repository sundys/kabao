# v1.0.15

## 修改

- 卡片新增“卡种”字段（如“白金卡”“标准卡”），允许为空，最多 20 字。
- 卡片录入界面调整：姓名输入框缩短（上限 10 字），右侧同行新增卡种输入框。
- 卡片列表改为三行显示：第一行姓名+卡种，第二行脱敏卡号，第三行有效期+备注；三行固定行高，卡种、备注为空时仍保持对齐。
- 卡片详情页新增“卡种”条目显示。
- 更新银行卡 CSV/XLS 批量导入模板：在“持有人姓名”后新增“卡种（可选）”列，表头全部使用中文标注；证件模板同步重新生成。

## 备份与导入

- 加密备份（.kabao）导出/导入已包含卡种字段；旧版本备份文件可正常导入（无卡种时视为空）。
- CSV 批量导入支持“卡种（可选）”列，超长内容会在预校验阶段报错且不会写入数据。
- 本次变更不改变数据库结构与加密格式，备份完全向后兼容。

## 安全与数据

- 卡种与姓名一样仅加密存储于本地，列表中不展示敏感明文，卡号仍按脱敏分组显示。
- 已通过 flutter analyze、152 项单元/组件测试与真机人工验证。
