# v1.0.30

## 修复

### 借记卡分类内编辑卡片：保存后停在编辑页、没有任何提示

- 在分类内打开已有卡片 → 修改 → 保存，数据其实已经写入，但编辑页既不关闭也不提示，看起来像没保存成功。
- 原因：保存时写库是异步的，控制器在这段时间内会被回收（分类列表被编辑页盖住时不再监听它）；写库完成后继续使用已回收的控制器刷新数据会抛异常，编辑页把异常当成「保存失败」处理，而失败提示又被随后的页面重建吞掉。
- 现在保存以「数据已落库」为准：控制器已被回收时改由依赖容器刷新相关数据，编辑页正常返回；意外异常也会明确提示「保存失败，请重试」，不会让用户误以为已保存。
- 同时修复了一个连带问题：从搜索结果直接打开详情再编辑时，卡片的**手动排序序号**会被清零。现在改为从库里读回原记录后再合并。

### 详情页编辑后返回，仍显示修改前的数据

- 卡片详情页与证件详情页改为在保存后重新读取该条记录（按主键单条解密），编辑返回后立即显示新值；此前的展示数据来自路由传入的快照，不会随保存更新。借记卡、信用卡、证件卡三种类型均已覆盖。
- 读取失败（例如记录已被删除）时回退到打开页面时的快照，页面不会空白。
