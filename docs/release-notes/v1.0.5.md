# v1.0.5

## 新增

- **银行卡 CSV 批量导入**：设置页新增“导入银行卡 CSV”，支持按中文模板批量导入借记卡和信用卡。
- **证件 CSV 批量导入**：设置页新增“导入证件 CSV”，支持按中文模板批量导入证件卡。
- **中文 CSV 模板**：新增银行卡和证件标准模板，字段名称使用中文；系统可生成字段标记为“（可选）”。
- **XLS 转 CSV 工具**：新增 `tools/xls_to_kabao_csv.py`，可将 Excel 97-2003 `.xls` 文件转换为 UTF-8 BOM CSV。
- **XLS 工具文档**：README 和 `docs/xls-to-csv.md` 增加安装、使用命令、字段映射和安全说明。

## 修改

- CSV 导入支持 UTF-8 BOM、标准 CSV 引号、单元格换行和中文/英文字段兼容。
- CSV 导入采用全量预校验：任意行存在错误时整批不写入数据库。
- 导入预览仅显示行数、记录数、新分类数和错误行号，不显示卡号、CVV、证件号等敏感内容。
- 导入数据通过现有加密数据库事务写入，并按 UUID 与更新时间规则合并，不删除已有数据。
- 卡号、证件号在 XLS 转换时检测数字精度风险，避免 Excel 普通数字格式造成长号码损坏。

## 安全提示

CSV 是明文迁移格式，不是加密备份格式。使用后请妥善删除源 XLS 和 CSV 文件；正式备份请使用加密的 `.kabao` 文件。
