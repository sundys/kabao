# v1.0.18

## 新增与改进

- **分类页（含证件分类）添加按钮移到标题右侧**：与首页样式一致，位于 AppBar 右上角；不再使用右下角悬浮按钮。
- **分类页右下角新增搜索入口**：与首页样式一致，位于右下角同位置。
- **搜索作用域区分**：
  - 进入分类后的搜索只搜索当前分类内的记录，不会返回其他分类的结果（不做全局搜索）。
  - 首页搜索入口保持不变，仍是全局搜索，覆盖全部借记卡、信用卡分类与证件卡。
  - 分类内搜索的提示文案改为「搜索本分类内的记录」，结果行不再重复显示分类名。
- 空列表提示由「点击右下角添加」改为「点击右上角添加」，与新的入口位置一致。
- 列表底部留白相应收窄（不再需要为右下角悬浮按钮让位），但仍保留右下角搜索入口的避让空间。

## 安全与数据

- 本次仅调整入口位置与搜索查询范围，不涉及数据库结构、加密格式、备份格式或权限变更。
- 搜索结果仍只展示脱敏后的卡号/证件号；分类内搜索只是缩小查询范围，不会放宽数据可见范围。

## 测试

- 新增 `test/features/wallet/category_detail_page_test.dart`：覆盖分类作用域搜索结果、添加按钮位置、右下角搜索入口位置与作用域。
- 集成测试改用 `byTooltip('添加卡片' / '添加证件')` 定位新入口，并补充分类内搜索与首页全局搜索两条路径的断言。
- 已通过 `dart format`、`flutter analyze` 与 `flutter test`（159 项）。
