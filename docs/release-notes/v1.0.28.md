# v1.0.28

## 优化

### 保存卡片不再转圈

- 编辑或新增卡片、证件后点击保存，此前要等待 1–3 秒才返回。原因是保存成功后同步执行了一整套与保存无关的工作：初始化通知插件、对全库每一张卡片和每一个证件逐一重算提醒、逐条解密通知快照，并为每个未到期档位重新编排一次 Android 闹钟。数据越多等待越久。
- 现在保存只写入记录并立即返回；提醒维护改到后台执行，失败静默并在下次解锁/回前台时全量补齐（该重算本就是幂等的）。
- 新增单记录重算：保存或删除一条记录只处理这一条记录的提醒档位，不再遍历全库。
- 仓储层 `getById` 改为按主键单行查询，不再为了取一条记录而解密整张表（分类、卡片、证件三处）。

### 删除确认框按钮布局

- 删除卡片/证件/通知、删除分类、清空数据等确认框里，「取消」被挤到「删除」上方单独占一行。原因是全局按钮主题设置了无限宽度，对话框的按钮容器只能逐个换行。
- 现在统一为左右两个等宽按钮，各占一半、中间留出间隔；分类下仍有卡片时只保留「取消」。

### 启动画面

- 冷启动时首帧之前是一段纯黑空窗。启动窗口背景改为与应用主题背景一致（浅色 `#F7FAF7` / 深色 `#101413`），并在中央显示应用图标。
- 首帧之后的窗口背景同步改为同一颜色，避免启动窗口到 Flutter 首帧之间的颜色跳变。

### 首页证件卡

- 证件卡面中央新增国徽标识，下方显示「证件卡包」。

## 修复

- 集成测试 `app_flow_test.dart` 中首页仿真卡是 `PageView`，第二页在滑动前不会构建，原用例的点击落空导致整条验收路径失败；改为先横向滑动再点击。

## 安全与数据

- 不改变数据库结构、加密格式、备份格式与提醒规则；所有数据仍仅以 AEAD 加密形式存于本机。
- 提醒维护改为后台执行后仍保持幂等：重复重算不会重复生成提醒，也不会重复写「已挂载闹钟」状态。
- 已通过 `dart format --set-exit-if-changed .`、`flutter analyze`（无问题）与 `flutter test`（215 项，新增 8 项覆盖单记录重算与删除确认框布局）。
- 在 MI 9（Android 9 / API 28）真机执行 `integration_test/app_flow_test.dart` 与 `document_flow_test.dart`，均通过；冷启动与证件卡显示已截图确认。
