# v1.0.11

## 界面

- 首页分类卡片更紧凑，空状态提示改为指向右上角新建入口。
- 新建分类入口移动到首页右上角，并按借记卡、信用卡、证件卡显示匹配文案。
- 右下角新增本地搜索入口，支持按姓名、卡号和分类查找卡片与证件。
- 分类卡片的右侧指示符调整为竖向三点，降低视觉噪音。

## 性能

- 主密码设置、解锁、修改密码与备份加解密中的 Argon2 派生移到后台 isolate，减少 UI 卡顿。
- 分类、卡片、证件列表按类型或分类条件过滤后再解密，减少锁定/解锁和页面切换时的额外工作。
- 提醒重算复用分类与通知快照，避免逐条查询导致登录后明显等待。
- 分类增删改不再整页刷新，设置项选择先更新界面再持久化。

## 安全与数据

- 本次变更不改变数据库结构、主密码、备份格式或认证加密参数。
- 搜索结果仅显示脱敏卡号/证件号，不记录查询内容，不引入新的联网功能。
