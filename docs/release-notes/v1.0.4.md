# v1.0.4

## 新增

- **自动锁定超时时间可自定义**：设置 → 安全 → 超时时间，提供 6 个档位：立即、30 秒、1 分钟、2 分钟、5 分钟、10 分钟。
  - 弹窗中实心圆点为当前档位，空心圆圈为未选中；点击即生效，选中状态持久保留，直到主动改选其它档位。
  - 档位写入加密的安全存储，重启应用后仍然有效。
  - 之前为固定的「切后台 10 秒锁定」，现由用户自行决定；默认档位为 30 秒。
  - 选择「立即」时，应用一退到后台就立刻锁定数据库，不再有延迟窗口。

- **证件号按 6/8/尾号分组显示**：录入与详情页统一显示为 `402356 20120226 3038` 的形式，长号码一眼能对齐，减少录入出错。
  - 分组只发生在显示层：入库、备份与复制出去的始终是连续数字，粘贴到别处不会带空格。

- **证件「长期有效」选项**：有效期限下方新增勾选框。
  - 勾选后自动清空并锁定上方的日期输入，保存时有效期限记录为「长期有效」。
  - 详情页与列表直接显示「长期有效」；这类证件不会产生到期提醒。
  - 取消勾选即恢复日期录入。加密备份新增 `validityPermanent` 字段，旧备份按非长期有效导入。

## 修复

- 修正 Android 签名配置读取 `key.properties` 的编码方式，含非 ASCII 字符的密钥库路径不再被解析错误。
