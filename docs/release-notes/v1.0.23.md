# v1.0.23

## 改进

- **安装失败后可直接重新安装，不再重新下载**：
  - 下载完成后仍然自动调起系统安装器，但更新窗口不再立刻关闭，而是留在后台等待。
  - 安装被取消或安装失败时，返回应用即可在窗口里看到「重新安装」，直接复用已经下载好的安装包；只有本地确实没有可用安装包时才会再次下载。
  - 安装成功时应用由系统结束并重启，窗口自然消失；从安装器返回时会比对已安装版本，版本已经提升则自动关闭窗口。
- 「前往发布页」只在本地没有可用安装包时出现，避免与「重新安装」并存造成困惑。
- 调起系统安装器失败时给出明确提示（点击「重新安装」重试），不再出现点击后毫无反应的情况。

## 安全与数据

- 只调整更新窗口的交互与按钮文案，不涉及业务数据、加密方案、备份格式或权限申请。
- 更新包仍然只放在应用私有缓存目录，且任何时刻最多只有一个：开始下载前清空缓存目录，应用启动时回收「当前安装版本已不低于缓存包版本」的安装包。
- 安装包文件不包含任何用户数据，网络请求仍只访问公开的 GitHub Release。

## 测试

- 新增 `test/features/settings/update_dialog_test.dart`（3 项）：①下载完成后自动调起安装器、窗口保留，安装未完成后点「重新安装」复用缓存包且没有第二次网络请求；②安装成功后从安装器返回时窗口自动关闭；③下载失败时给出「重试」与发布页入口。
- `ApkInstaller` 由静态方法改为常量类上的实例方法，便于在测试中替换平台实现；调用点仅更新窗口一处。
- 已通过 `dart format --set-exit-if-changed .`、`flutter analyze` 与 `flutter test`（182 项）。
- 真机流程（下载 → 系统安装器 → 安装失败返回 → 重新安装）需在发布出比当前安装版本更新的版本后手工确认。
