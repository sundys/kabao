# v1.0.20

## 新增

- **应用内检测更新**：设置 → 关于卡包 → 「检测更新」（原来的「最新版本下载」入口）。
  - 只有你手动点击才会联网，应用不会后台自动检测。
  - 检测到新版本时弹出更新窗口：显示版本变化（如 `v1.0.19 → v1.0.20`）与更新说明，可选择「立即更新」。
  - 下载过程显示百分比、已下载体积与实时速度。
  - 下载完成后调用系统安装器安装；安装前检查「安装未知应用」权限，未授权时跳转系统设置，返回后自动继续安装。
  - 若该版本没有适配本机 CPU 架构的安装包，会引导到发布页手动下载。
- **GitHub 加速**：检测与下载都会依次尝试直连和常用加速前缀（`ghfast.top`、`gh-proxy.com`、`ghproxy.net`、`mirror.ghproxy.com`、`hk.gh-proxy.com`）。如果加速服务只转发 `github.com`、不转发 `api.github.com`，会自动退回发布页读取版本标签。

## 改进

- **搜索面板不再默认展示记录**：首页全局搜索与各分类（子标签页）内的搜索，打开后只显示提示文案，输入关键词后才开始查找。
  - 关键词为空时不再读取整库记录，减少不必要的内存占用。
  - 搜索框新增清除按钮，方便连续检索。

## 安全与数据

- 检测更新只读取公开的 GitHub Release 信息，不带任何本地数据；不接入业务后端、不上传分析数据。
- 新增权限仅两项：`INTERNET`（用户手动触发检测/下载时使用）与 `REQUEST_INSTALL_PACKAGES`（把更新包交给系统安装器）。
- 更新包只写入应用私有缓存目录，通过 FileProvider 以 `content://` 临时授权给系统安装器，不申请宽泛存储权限。
- 不改变备份格式、数据库结构与加密方案。

## 测试

- 新增 `test/features/settings/update_service_test.dart`（12 项）：版本比较、按 ABI 选包、代理依次重试、无 Release、以及 API 不可用时退回发布页推导 APK 地址。
- 更新搜索相关用例以匹配新的默认空态行为；分类内搜索改用能同时命中两个分类的关键词，真正验证作用域隔离。
- 已通过 `dart format`、`flutter analyze` 与 `flutter test`（173 项），并成功构建 debug APK 验证 Android 侧改动。
