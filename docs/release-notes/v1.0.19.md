# v1.0.19

## 修复

- **修复导出备份无法保存**：在设置页点击「导出备份」并设置备份密码后，保存位置对话框不会出现，也没有任何错误提示；再次点击只会重复弹出设置密码窗口。
  - 原因：`file_picker` 10.x 在 Android/iOS 上的 `saveFile` 必须同时传入待写入的字节，缺少时直接抛 `ArgumentError`。原实现既没有传字节，又把该调用放在了错误捕获之外，异常被静默丢弃。
  - 现在会在内存中先完成加密，再把密文交给保存位置对话框，由系统存储访问框架（SAF）一次写入。
- 导出流程整体纳入错误处理：任何一步失败都会提示「导出失败，请重试」，不再出现"点击后毫无反应"的情况。

## 安全与数据

- 备份仍在本地完成全部加密后才写入目标位置，目标文件只包含密文；失败或取消时不会留下半成品文件。
- 不改变备份格式（`kabao-backup` v1）、数据库结构或加密方案，旧备份仍可正常导入。

## 测试

- 新增 `test/features/backup/export_flow_test.dart`：驱动真实导出流程，断言 `saveFile` 收到非空密文、落盘产物可被备份密码解密，且文件中不含分类名或卡号明文。
- 回归保护：把修复还原成旧写法时该用例会失败。
- 已通过 `dart format`、`flutter analyze` 与 `flutter test`（161 项）。
