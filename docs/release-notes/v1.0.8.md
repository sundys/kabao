# v1.0.8

## 修改

- 首页移除顶部“卡包”标题行，减少重复层级并让内容区域更紧凑。
- 借记卡、信用卡、证件卡改为居中紧凑的三栏焦点标签，当前标签始终位于中央并突出显示。
- 左右相邻标签采用低透明度和轻微模糊效果，强化当前标签的视觉焦点。
- 支持标签点击及左右滑动切换，三种卡片类型可在循环序列中连续滚动。
- 移除胶囊形选中指示器，底部分隔线调整为与主题协调的浅灰色。
- 修正顶部标签栏与系统状态栏重叠的问题，改为在安全区域内布局。
- 发布构建仅保留 arm64-v8a 与 armeabi-v7a APK，移除 x86_64 架构产物。

## 验证

- Flutter 全量测试通过（145 项）。
- Android Debug APK 构建并通过 ADB 安装到真机验证启动。
