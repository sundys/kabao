# v1.0.22

## 改进

- **关于卡包页面入口简化**：
  - 「开源主页」不再把网址显示在下方，四个字本身改为超链接样式（主题色 + 下划线），点击跳转到 GitHub 主页。
  - 「检测更新」去掉下方的说明文字。
  - 「CSV 批量导入模板下载」去掉下方的说明文字，仍保留超链接，点击跳转到模板目录。
- 跳转失败时（例如设备没有可用浏览器）会提示「无法打开链接，请检查是否已安装浏览器」，不再点击后毫无反应。

## 安全与数据

- 仅调整关于页的展示与跳转，不涉及数据、权限、加密方案或备份格式。

## 测试

- 新增 `test/features/settings/about_page_test.dart`（5 项）：副标题已移除、链接样式与普通样式的区分、点击开源主页与模板下载分别跳转到正确地址、跳转失败时的提示。
- 已通过 `dart format`、`flutter analyze` 与 `flutter test`（179 项）。
