# v1.0.21

## 修复

- **更新包不再累积占用空间**：v1.0.20 下载的更新包按版本命名（`kabao-<版本>.apk`），安装完成后不会删除，每升一个版本就会在应用缓存里多留一个 20MB 上下的安装包。现在：
  - 每次开始下载前清空更新包缓存目录，任何时刻最多只存在一个安装包；
  - 每次点击「检测更新」时回收上一次更新留下的安装包；
  - 应用启动时回收「当前安装版本已不低于缓存包版本」的安装包；仍在等待你确认安装的包会保留，避免系统安装器读不到文件。

## 说明

- 更新包始终放在应用私有缓存目录，即使清理逻辑因为权限或异常没有执行，系统在存储紧张时也会自行回收，你也可以在系统「应用信息 → 存储 → 清除缓存」中手动清理。
- 不改变备份格式、数据库结构与加密方案。

## 测试

- 新增「下载前清掉历史版本与半成品，只保留本次安装包」用例。
- 已通过 `dart format`、`flutter analyze` 与 `flutter test`（174 项）。
