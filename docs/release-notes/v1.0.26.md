# v1.0.26

## 修改

### 额度管理

- 卡片新增“额度（元，可选）”字段，旁边提供“计入总额”复选框，默认勾选；未勾选的卡片不计入总额。
- 卡片详情页显示额度（千位分隔，如 ¥50,000），未计入总额时明确标注。
- 首页信用卡仿真卡显示总授信额度：自动汇总所有勾选“计入总额”的信用卡额度。

### 全新首页

- 顶部原标签栏位置改为居中的椭圆胶囊搜索框，两侧留白；点击弹出全屏透明磨砂背景的动态搜索层，输入即时过滤，未输入时不展示任何记录。
- 导航栏下方新增三个圆形统计：借记卡/信用卡/证件卡各自的总张数（加粗数字+类型名），圆的直径随屏幕尺寸自适应；右下角悬浮搜索按钮移除。
- 三个圆形统计下方为三张可左右滑动的仿真卡片：借记卡/信用卡为纯黑高端卡面，左中芯片标识、右下银联标识；证件卡以身份证背景图呈现；卡片上方有圆点指示器，卡面显示类型、张数与（信用卡）总授信额度。
- 点击仿真卡或圆形统计进入对应类型的固定分类页；原顶部滑动标签栏完全移除，三个类型各自独立成页，页内搜索只搜当前类型，首页搜索为全局。
- 新增“待办提醒”栏：汇总卡片有效期、U 盾证书、证件有效期限的即将到期/已到期事项，按紧急度排序，已到期红色、临期橙色标识，点击直达对应记录。

### 其他调整

- 主密码（首次设置、修改密码）与备份密码的最小长度由 8 位调整为 6 位；旧备份文件不受影响。
- 银行卡 CSV/XLS 导入模板新增“额度（可选）”“计入总额（可选）”列，表头中文标注；转换脚本同步支持。
- 修复导入完成提示显示为“instance of 'ImportResult'”的问题，现在显示新增/更新的分类与记录数量。

## 安全与数据

- 额度字段与既有字段一样仅加密存储于本机；列表和待办中卡号/证件号保持脱敏显示。
- 本次变更不改变数据库结构与加密格式；旧版本数据与备份文件可直接升级/导入，双向兼容。
- 生物识别、加密体系、锁定逻辑未改动。
- 已通过 flutter analyze、207 项单元/组件测试与真机集成测试。
