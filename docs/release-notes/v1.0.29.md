# v1.0.29

## 界面优化

### 设置页重新排版

- 设置项由零散的整行列表改为**分组卡片**：外观、安全、数据、危险操作、关于各自一张圆角卡片，卡片内条目之间用细分隔线区隔。
- 每个条目左侧新增 36×36 的圆角图标底纹，按分组使用不同的强调色（安全组暖金、数据组冷蓝、外观组薄荷绿），比原来清一色的线性图标更容易扫读。
- 条目右侧统一增加「>」指示符，明确表示可进入下一级；分组小标题改为低饱和、加字距的样式。
- 「清空全部数据」从数据分组中移出，独立为「危险操作」分组，图标、标题与底纹均使用错误色，降低误触概率。
- 两处原本为空的副标题补充了说明：「修改主密码」→「重新派生密钥并迁移加密数据」，「关于卡包」→「版本信息、开源主页与更新」。

## 修复

- 分组卡片最初使用带背景色的容器，会遮挡 `ListTile` 的点击水波纹并触发 Flutter 断言；改为以 `Material` 作为卡片底色后，点击反馈恢复正常。

## 功能与数据

- 设置项数量、文案、点击行为与开关逻辑均未改动；主题切换、超时时间选择、生物识别开关、导入导出、WebDAV、清空数据等入口保持原样。
- 不涉及数据库结构、加密方案、密钥派生或备份格式，不新增任何权限或联网行为。
- 已通过 `dart format --set-exit-if-changed .`、`flutter analyze`（无问题）与 `flutter test`（218 项，新增 3 项覆盖分组标题、设置项文案与交互）。
- 在 MI 9（Android 9 / API 28）真机上确认深色与浅色两种主题下的排版，并验证主题弹窗、超时时间弹窗交互正常。
