# v1.0.17

## 修复与改进

- 深入排查 v1.0.16 证件 CSV 导入问题：经真机安装包反查确认 v1.0.16 已包含“证件卡”取值修复；本次针对仍可能失败的两种场景加固：
  - 分类类型、记录类型列现在会自动去除所有空白字符（含不间断空格、全角空格）后再比对，避免 Excel 复制带来的隐藏空格导致校验失败。
  - 若证件数据误从“批量导入借记卡/信用卡”入口导入，错误提示会直接指引用户改用“批量导入证件”入口。
- 校验失败提示现在会回显分类类型的实际填写值（该字段非敏感），便于快速定位表格中的问题单元格。

## 安全与数据

- 错误提示仅回显“分类类型/记录类型”这类非敏感的表格取值，不涉及卡号、CVV、证件号等敏感字段。
- 不改变数据库结构、加密格式或备份兼容性。
- 已通过 flutter analyze 与 156 项单元/组件测试。
