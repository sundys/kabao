# v1.0.25

## 修复

- **长按文本框弹出的菜单是英文**：新增/编辑卡片、身份证、备注等输入框里长按选中内容时，浮出的「Cut / Copy / Paste / Select all」是 Flutter 内置组件的默认英文文案——应用此前没有声明本地化代理，内置组件一律回退到英文。
  - 现在接入 `flutter_localizations`，并把应用语言固定为 `zh-CN`，文本框长按菜单显示为「剪切 / 复制 / 粘贴 / 全选」。
  - 同一处修复也覆盖其它内置文案：输入框的自动填充/拼写等语义标签、无障碍朗读文本、对话框与各类控件的默认提示。
  - 应用业务文案本就是硬编码中文，因此固定 `zh-CN` 不会改变既有界面文字，只是让内置组件与应用保持一致。

## 安全与数据

- 不涉及加密方案、密钥派生、数据库结构、备份格式或权限申请，仅是界面文案与本地化配置。
- 未新增任何联网、统计或第三方依赖；`flutter_localizations` 随 Flutter SDK 提供，`intl` 由 0.20.3 回落到 SDK 约束的 0.20.2。
- 复制卡号仍走原有的 `ClipboardService`（无空格数字、离开前台尽力清理），本次未改动复制逻辑；长按菜单中的「复制」只在用户主动选择时触发，与列表/详情页的复制按钮行为一致。

## 测试

- 新增 `test/app/localization_test.dart`（2 项）：
  - 验证 `KabaoApp` 下 `MaterialLocalizations` / `CupertinoLocalizations` 的复制、剪切、粘贴、全选文案均为中文；
  - 长按文本框后弹出的菜单显示「全选」且不出现任何一个英文项（去掉本地化代理时该用例会失败，可作回归防护）。
- 已通过 `dart format --set-exit-if-changed .`、`flutter analyze`（无问题）与 `flutter test`（197 项）。
- 真机建议手工确认：新增/编辑卡片时在卡号、备注等输入框内长按选中内容，菜单应显示中文；搜索框、WebDAV 设置等输入框同理。

## 已知限制

- 输入框上方由 Android 系统提供的项目（如「自动填充」「翻译」「扫描文字」）跟随系统语言，不由应用控制。
- 应用仍为中文单语言，未提供语言切换；若后续需要多语言，需先引入业务文案的资源化管理。
